# Biodiversity Finance — Data-Source Review

An exploratory research archive on **biodiversity-finance data availability, structure and accessibility**. The public files primarily contain research documents, a source-validation note and supporting figures, rather than a packaged application.

## Start here

- [`02_bdf_research_question_scope.pdf`](./02_bdf_research_question_scope.pdf) — research question and scope.
- [`01_bdf_mlr_methodology.pdf`](./01_bdf_mlr_methodology.pdf) — methodology documentation.
- [`Validation_of_Biodiversity_Finance_Data_Sources.pdf`](./Validation_of_Biodiversity_Finance_Data_Sources.pdf) — source-review material.
- [`Appendix_Table_A1.pdf`](./Appendix_Table_A1.pdf) — supporting table.
- Figures in this repository — visual summaries of the data-source assessment.

## How to interpret

The files show research framing, assessment artefacts and visualisations. They should not be read as a claim that every candidate dataset has been independently audited, licensed for redistribution or shown to support an investable strategy. Refer to the methodology and underlying source material before citing any result.

**Relevant methods:** desk research, evidence screening, data-source comparison and reproducible research documentation.
